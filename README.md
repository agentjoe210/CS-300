# CS-300
CS 300 class work


What was the problem you were solving in the projects for this course?

The problem we were tasked with solving was sorting through a csv or excel sheet and putting it into a sorting algorithm where it could be easily searched for and printed if desired.
This would enable the adminstrators to easily find course numbers to better help students with solutions

How did you approach the problem? Consider why data structures are important to understand.

I ended up writing the code to be sorted into a hash table which made looking up course quick and easy but was not necessarily easy for sorting the system as much as a Tree would have been. If I had to do it again, I would have done it in a binary tree to mitigate issues when more courses are added to the system, but for the small sample we used my system was fine. Data structures are important to understand in this context because all data struictures have their uses and can be detrimental to the task you need done if you choose the wrong one. I made this mistake but I know better now so hopefully I will not make this mistake in the future, although in real world scenarios you would likely be making this decision as a team.

How has your work on this project expanded your approach to designing software and developing programs?

This project has helped me with my understanding of object oriented programming and integrating files into the written software. I had little idea how to insert readable files into code before this project and this course has been a crash course into how to accomplish this task, although at a small scale.

How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

I made a deliberate decision to get my main() function to be as small as possible using object oriented approach. With a majority of my code in the HashTable object and the main menu in a seperate fuction I was able to get the main fuction down to just 3 lines which made it very maintainable and readable whenm issues occurred. I think the code is adaptable as well but it would have to be a very similar project to be of any use since it is a hash table
